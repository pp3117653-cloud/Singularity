## 🎯 Response Modes Explained

### 1. **Single Best Model**
Uses the historically best-performing model
- Fastest response time
- Most reliable based on history
- Ideal for quick answers

### 2. **Ensemble**
Combines all 3 models for comprehensive answer
- Most thorough response
- Covers all perspectives
- Highest quality but slower

### 3. **Competitive**
First model to respond wins
- Good balance of speed/quality
- Uses available model first
- Fallback to others if fails

### 4. **Consensus**
Models vote on best answer
- Democratic approach
- Validates answer quality
- Good for critical decisions

### 5. **Intelligent Routing**
System automatically selects best model
- Query-aware routing
- Performance-based selection
- Adaptive algorithm

### 6. **Chain of Thought**
Sequential reasoning with all models
- Most comprehensive analysis
- Step-by-step reasoning
- Best for complex problems

## 📊 Model Statistics

- **Success Rate**: Percentage of successful responses
- **Avg Response Time**: Average response latency in milliseconds
- **Quality Score**: Combined metric of success + speed
- **Rating**: Overall model performance rating

## 🔧 Installation

1. Download APK from releases
2. Enable "Unknown Sources" in Android settings
3. Install APK
4. Open Singularity app
5. Start asking questions!

## 🚀 Usage

1. Enter your prompt in the text field
2. Select desired response mode from dropdown
3. Click "Get Response"
4. View response and statistics
5. Long-press button for settings

## 🎓 How It Works

1. **Query Submission**: You enter a prompt
2. **Mode Selection**: System or user selects response mode
3. **Model Processing**: Selected models process query
4. **Response Aggregation**: Responses are combined/filtered
5. **Performance Tracking**: Metrics are recorded
6. **Result Display**: Final response is shown with stats
7. **Caching**: Response is cached for future use
